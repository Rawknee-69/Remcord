# Electron-to-WebView2 source map

This is the pre-adapter inventory for the Rust prototype. The Electron sources remain the behavioral specification; this prototype does not implement the compatibility adapters listed below.

“Boot required” means necessary to open Discord in a bare WebView, not necessary to preserve every existing Legcord feature. Injection and the renderer bridge are also tested in this prototype even though bare Discord can load without them.

| Electron capability | Current Legcord call sites / contract | WebView2 equivalent | Migration difficulty | Boot required? | Can defer? |

| `webContents` | `window.ts` owns navigation, reload, title/focus/maximize; `ipc.ts` sends native updates | `CoreWebView2` events and controller | High: event coverage differs and needs one owner | Yes: navigation/view | Most parity behaviors can defer |

## Prototype boundary

`native/src/main.rs` is deliberately independent of the existing Electron implementation. It uses the fixed DEV profile `E:\Legcord.webview-dev-user-data`, visits `https://discord.com/app`, limits top-level navigation to HTTPS Discord hosts, accepts bridge messages only from `https://discord.com`, and has no general-purpose host invocation command. Electron features above must not be treated as implemented just because the browser can display Discord.
